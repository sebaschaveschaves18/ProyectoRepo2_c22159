# Reporte Ciudadano - Frontend (Proyecto 2)

Aplicación React (Vite) con React Router y Bootstrap 5 que consume la API Django del Proyecto 1.

```
npm install
Copy-Item .env.example .env
npm run dev
```

La guía completa de instalación (backend + frontend), CORS, usuarios de prueba y limitaciones está en el `README.md` de la carpeta principal del repositorio.
